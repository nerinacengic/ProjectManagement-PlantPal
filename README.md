Plant Pal is a project centered around developing a plant care application, including a companion website. Throughout the exercises, I worked through the full project lifecycle — from initiation and planning to execution, monitoring, and closing — applying practices such as:

Defining project scope, goals, and deliverables
Creating a project charter and stakeholder analysis
Building project schedules and budgets
Identifying and managing risks
Developing a communication plan
Applying Agile principles (sprint planning, backlogs, retrospectives)
Managing quality, procurement, and vendor coordination
Creating and maintaining organized project documentation
This repository serves as a centralized location for all the documentation 
I produced during the certificate program, including project charters, RACI charts, 
risk registers, communication plans, budgets, schedules, and Agile artifacts — all created in the context of the Plant Pal project.
